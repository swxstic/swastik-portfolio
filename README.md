# Swastik Verma — Portfolio

Personal portfolio of Swastik Verma, first-year B.Tech student in Computer Science & AI at Rishihood University with Newton School of Technology.

## What's inside

- `index.html`: the whole site (HTML, CSS and JavaScript in one file)
- `assets/`: University of Michigan / Coursera certificate images

## Features

- Particle name in the hero that reacts to the cursor
- Smooth scrolling and scroll-driven animations (GSAP ScrollTrigger + Lenis)
- A working terminal you can type commands into
- "What I bring to the table": strength cards dealt onto a table as you scroll, with proof for each
- 3D certificate cards with a full-size viewer and Coursera verify links
- Contact form delivered by Web3Forms, with FormSubmit as a backup and an email-app fallback
- "Afterglow", an ambient music track generated live with the Web Audio API

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Deploy

Hosted on Vercel as a static site. Every push to `main` redeploys automatically.
