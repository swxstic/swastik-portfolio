Method

How I work through a problem, shown on a small one: find the top three scores in a class.

01

Understand it

Read the problem twice. Write down what’s given, what’s asked, and what “done” looks like.

# given: marks = [72, 91, 85, 91, 60]
# asked: the top 3 different scores
# done:  [91, 85, 72]
02

Make it smaller

Split it into pieces I can check on their own. Most big problems are a few small ones stacked together.

# 1. remove the duplicate 91
# 2. sort from high to low
# 3. keep the first three
03

Build the rough version

Get something working before making it pretty. A program that runs teaches me more than a plan that doesn’t.

def top3(marks):
    return sorted(set(marks), reverse=True)[:3]

print(top3(marks))   # [91, 85, 72]
04

Break it on purpose

Feed it the empty list, the one-item list, the list where everyone scored the same. Edge cases are where problems hide.

print(top3([]))         # []
print(top3([50]))       # [50]
print(top3([7, 7, 7]))  # [7]
05

Clean up and commit

Name things clearly, delete what isn’t needed, and write a commit message my future self will understand.

$ git add top3.py
$ git commit -m "Add top3() with edge-case tests"
$ git push origin main
